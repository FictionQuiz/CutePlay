# CutePlay

Cute friendship games, fun personality quizzes, interactive challenges and shareable results. Play, laugh & share!

## Project files

- `index.html` — homepage and game library
- `style.css` — responsive pastel design
- `script.js` — interactive mini-games and shareable results
- `assets/favicon.svg` — site icon

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. The site will be published at:

https://fictionquiz.github.io/CutePlay/

Game results are designed for entertainment only. Name-based results are playful, not real predictions or compatibility assessments.
